# The Open Brew: A Decentralized Cooperative Platform for Coffee Communities

> **Bogazici University**  
> *Department of Computer Engineering*  
> **Author:** Gökay Temizkan

This repository contains the report and supporting materials for **The Open Brew**, a decentralized, open, and cooperative social media platform designed to connect coffee enthusiasts, farmers, roasters, and baristas worldwide.

## Project Overview

The Open Brew aims to:
- Foster a global coffee community based on decentralization, openness, and cooperation.
- Promote four main pillars: **access**, **direct sourcing**, **home brewing**, and **education**.
- Enable data-driven analysis of community dynamics using network analysis techniques.

## Repository Structure

- `report.tex` — Main LaTeX report describing the platform model, methodology, and use case.
- `appendix.tex` — Supplementary materials, data examples, and pseudocode.
- `references.bib` — Bibliography file for cited works.
- `example_post.png` — Example post image used in the report.
- `votes_graph.py` — Python script for constructing the votes network graph.
- `comments_graph.py` — Python script for constructing the comments network graph.
- `requirements.txt` — Python dependencies for running the analysis scripts.
- `Readme.md` — This documentation file.

## Compiling the Report
   Ensure  a LaTeX distribution is installed (e.g., TeX Live, MikTeX).

   Compile `report.tex` to generate the final PDF.
